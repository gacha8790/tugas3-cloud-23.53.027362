MATERI PEMBELAJARAN

Mengenal Komputasi Awan

Memahami konsep cloud computing, jenis layanan, serta manfaat dan risiko penggunaannya.

01 / PENGERTIAN

Apa itu komputasi awan?

Komputasi awan (cloud computing) adalah teknologi yang memungkinkan pengguna mengakses sumber daya komputasi seperti server, penyimpanan data, basis data, jaringan, dan perangkat lunak melalui internet. Dengan teknologi ini, pengguna tidak harus menyediakan dan mengelola seluruh infrastruktur sendiri karena sumber daya tersebut disediakan oleh penyedia layanan cloud.

02 / JENIS LAYANAN

Tiga model layanan cloud

SaaS

Software as a Service

Layanan perangkat lunak yang dapat digunakan langsung melalui internet tanpa perlu memasang atau mengelola infrastruktur aplikasi.

Contoh: Google Docs, Gmail, dan Microsoft 365.

PaaS

Platform as a Service

Layanan yang menyediakan platform untuk mengembangkan, menguji, dan menjalankan aplikasi. Pengguna dapat berfokus pada pembuatan aplikasi tanpa mengelola server secara langsung.

Contoh: Google App Engine dan Heroku.

IaaS

Infrastructure as a Service

Layanan penyediaan infrastruktur komputasi virtual seperti server, jaringan, dan penyimpanan. Pengguna memiliki kendali lebih besar terhadap sistem yang digunakan.

Contoh: Amazon EC2 dan Google Compute Engine.

03 / MANFAAT

Manfaat komputasi awan

  • Fleksibel: data dan aplikasi dapat diakses dari berbagai perangkat selama terhubung ke internet.
  • Efisiensi biaya: mengurangi kebutuhan membeli dan merawat server sendiri.
  • Mudah dikembangkan: kapasitas penyimpanan dan komputasi dapat disesuaikan dengan kebutuhan.
  • Kolaborasi: beberapa pengguna dapat mengakses dan mengerjakan dokumen bersama.
04 / RISIKO

Risiko penggunaan cloud

  • Ketergantungan internet: akses layanan dapat terganggu ketika koneksi internet bermasalah.
  • Keamanan data: data perlu dilindungi dengan kata sandi kuat dan pengaturan akses.
  • Gangguan layanan: layanan penyedia cloud dapat mengalami pemeliharaan atau gangguan.
  • Ketergantungan penyedia: perpindahan layanan ke penyedia lain dapat membutuhkan waktu dan penyesuaian.
INTI PEMBELAJARAN

Komputasi awan memberikan kemudahan akses, fleksibilitas, dan efisiensi. Namun, pengguna tetap perlu memperhatikan keamanan data, koneksi internet, serta ketentuan dari penyedia layanan.
